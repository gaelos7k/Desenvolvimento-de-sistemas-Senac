# Fluxogramas — UC3

Visão geral
Pasta com fluxogramas em formato Draw.io (.drawio) usados para representar visualmente a lógica de resolução de exercícios e algoritmos.

Como abrir

- Use draw.io para abrir e editar os arquivos `.drawio`.
- Arquivos `.png` e `.pdf` (quando presentes) são versões exportadas para visualização rápida.

Conteúdo e exemplos

- `01 Calculadora Simples.drawio`
- `02 Verificador de Idade para Voto.drawio`
- `03 Conversor de Temperatura.drawio`
- `07 Simulador de Caixa Eletrônico.drawio`
- `Fluxograma1.drawio`, `Fluxograma2.drawio`, `Fluxograma3.drawio`
