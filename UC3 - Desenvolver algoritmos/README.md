# UC3 — Desenvolver algoritmos

Visão geral
Este diretório contém materiais práticos da unidade "Desenvolver algoritmos": fluxogramas (.drawio), pseudocódigos (.ALG) e listas de exercícios. O objetivo é praticar pensamento algorítmico, estruturas de controle, vetores e manipulação de dados.

Estrutura do diretório

- `FLUXOGRAMAS/` — arquivos `.drawio` e imagens exportadas com diagramas de fluxo.
- `ALGORITMOS/` — pseudocódigo em `.ALG` por atividade.
- `Exercicios/` — materiais em PDF e listas de exercícios.
- `Aula Integrada RH e Sistemas/` — material complementares.

Como usar

1. Abra os arquivos `.drawio` com draw.io para visualizar ou editar os fluxogramas.
2. Abra os arquivos `.ALG` com Visualg e use como referência para implementar soluções em Python, JavaScript ou outra linguagem.

Principais exercícios

- Contador de 1 até N
- Conversor de temperatura
- Verificador de triângulo
- Simulador de caixa eletrônico
- Sistema de login simples
