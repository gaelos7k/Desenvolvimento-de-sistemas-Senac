# Projeto 02 — Listas e exemplos de arquivos

Visão geral

`projeto02` contém exercícios sobre manipulação de listas e leitura/escrita de arquivos (ex.: `lista.py`, `lista02.py`) e exemplos de dados em `.txt`.

Como executar

1. Criar e ativar ambiente virtual:

```powershell
python -m venv venv; .\venv\Scripts\Activate.ps1
```

2. Executar o script exemplo:

```powershell
python lista.py
```
