# Projeto 01 — Aplicações desktop (Exemplos)

Visão geral

Este subprojeto contém exemplos simples de aplicações e utilitários em Python (ex.: `interface.py`, `imc.py`, `gasto_calorico.py`). Serve como base para praticar scripts CLI e funções utilitárias.

Como executar

1. Criar e ativar um ambiente virtual:

```powershell
python -m venv venv; .\venv\Scripts\Activate.ps1
```

2. Executar um dos scripts:

```powershell
python interface.py
# ou
python imc.py
```
