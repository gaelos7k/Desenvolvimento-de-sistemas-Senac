# UC4 — Programação estruturada e orientação a objetos

Visão geral

Conteúdos sobre programação estruturada e orientação a objetos (OOP) com exemplos em JavaScript e exercícios front-end. Contém exemplos de abstração, herança e polimorfismo, além de projetos de front-end para prática.

Estrutura do diretório

- `abstracao.js`, `heranca.js`, `polimorfismo.js` — exemplos em JavaScript demonstrando conceitos OOP.
- `front-end/`, `Aula18jun25/` — exemplos de HTML/CSS/JS para exercícios práticos.
- `Linktree/` — mini projeto estático com `index.html` e `style.css`.
- `images/` — imagens de apoio.

Como usar

- Abra `index.html` no navegador para ver os exemplos de front-end.
- Confira os arquivos `.js` para entender implementações de abstração, herança e polimorfismo.
