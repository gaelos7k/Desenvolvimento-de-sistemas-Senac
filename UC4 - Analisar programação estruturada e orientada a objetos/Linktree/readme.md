# Linktree — Mini projeto front-end

Visão geral
Projeto estático que simula uma página tipo Linktree. É composto por HTML, CSS e imagens para demonstrar layout simples e estilização.

Estrutura

- `index.html` — página principal.
- `style.css` — estilos do projeto.
- `images/` — imagens e ícones utilizados.

Como visualizar

- Abra `index.html` no navegador (duplo-clique).
