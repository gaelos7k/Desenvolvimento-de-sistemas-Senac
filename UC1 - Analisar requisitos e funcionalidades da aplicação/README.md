
# UC1 — Analisar requisitos e funcionalidades da aplicação

Visão geral
Este diretório reúne artefatos de análise de requisitos usados na unidade curricular: briefings, estudos de caso, diagramas de casos de uso e diagramas de classe, além de apresentações e material de aula. O objetivo é ajudar na captura e especificação de requisitos funcionais e não-funcionais.

Sumário
- Visão geral
- Estrutura do diretório
- Arquivos principais

Estrutura do diretório
- Briefing Word/: documentos Word com briefings (ex.: "Sala Maker", "Roger Guedes Personal").
- Estudo de caso/: estudos de caso em Word/PDF (ex.: Recolhe Já, WorkShare).
- Diagramas de caso de uso/: arquivos `.drawio` e imagens exportadas com casos de uso.
- Diagramas de classe/: arquivos `.drawio` e imagens com modelos de classe.
- Apresentações/: slides relacionados aos projetos e requisitos.
- Aula/: material didático da disciplina.


Arquivos principais
- `Briefing Word/Briefing - Sala Maker.docx` — briefing completo com lista de requisitos.
- `Estudo de caso/Estudo de Caso Recolhe Já.docx` — estudo de caso com atores e fluxos principais.
- `Diagramas de caso de uso/*.drawio` — diagramas editáveis.
