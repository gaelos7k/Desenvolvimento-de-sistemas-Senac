Abstração no banco de dados é abstrair algumas informações peguemos funcionário por exemplo: Uma tabela funcionários pode envolver o garçom, caixa e cozinheiro. Não há necessidade de uma tabela para cada funcionário.

SGDB (Sistema de gerenciamento de banco de dados) - Usaremos o MySQL, mongoDB ou firebase

Para um SGDB ser completo le precisa de dados, software, hardware e usuários.

Dentro do SGDB é possível programar uma rotina de backup para segurança dos dados, visto que empresas já faliram por não ter banco de dados com backup.

SHOW TABLES; - Mostra as tabelas do banco de dados.

INSERT INTO `usuários` (params1, params2)

SELECT * FROM usuários; - Mostrar os valores inseridos na tabela
RENAME  'nome da tabela'  TO  'nov nome da tabela'; - Renomeia a tabela
SELECT * FROM  'nome tabela' WHERE id_usuarui = 456; - Seleciona todas informações de um usuário com id específica.
SELECT id_usuario FROM usuarios; - Seleciona todos ID de usuários apenas.
UPDATE usuarios SET id_usuario = 4 WHERE nome ='Beatriz'; - Atualizar o id_usuario para o valor setado onde o nome é 'Beatriz'.
 ALTER TABLE usuarios RENAME COLUMN id_usuario TO id_usuarios; - Renomeando uma tabela, apenas trocando o nome.

SELECT c.comentario, u.nome FROM comentarios c INNER JOIN usuarios u ON c.id_usuarios = u.id_usuarios WHERE c.id_usuarios = 1; - Selecionando com alias as duas tabelas para referencias e conseguir dados das duas tabelas a partir de id_usuarios que é comum nas duas tabelas.
