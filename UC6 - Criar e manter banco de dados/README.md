# UC6 — Criar e manter banco de dados

Visão geral

Pasta com materiais de modelagem de dados, exemplos SQL e documentos de apoio para a construção e manutenção de bancos de dados. Útil para estudar modelagem (DER/ER), comandos SQL e permissões de acesso.

Sumário

- Visão geral
- Estrutura do diretório
- Como usar
- Arquivos principais
- Próximos passos

Estrutura do diretório

- `Minimundo loja de jogos.docx` — descrição do minimundo para modelagem.
- `Banco de dados SQL (1).docx` — material teórico/prático sobre SQL.
- `Primeiro banco de dados.txt`, `Treinando comandos de consulta em um banco de dados existente.txt` — exemplos de consultas e comandos.
- `avaliacao_DER.drawio.pdf` — diagrama ER/DER.

Como usar

1. Abra `avaliacao_DER.drawio.pdf` para ver o diagrama ER.
2. Utilize os arquivos `.txt` como scripts de exemplo para treinar queries em um SGBD (MySQL, PostgreSQL, SQLite).
