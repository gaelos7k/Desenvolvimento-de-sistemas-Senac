# Repositório de Estudos — Curso Técnico em Desenvolvimento de Sistemas (SENAC Minas)

Este repositório centraliza os materiais estudados ao longo de 1 ano e meio do curso técnico de Desenvolvimento de Sistemas no SENAC Minas (Pouso Alegre, MG). Aqui você encontrará documentos, diagramas, exercícios e pequenos projetos organizados por unidades curriculares (UCs).

## Estrutura do repositório

- `UC1 - Analisar requisitos e funcionalidades da aplicação/` — briefings, estudos de caso, diagramas de caso de uso e diagramas de classe.
- `UC2 -  Auxiliar na gestão de projetos de Tecnologia da Informação/` — EAP, protótipos e guias de planejamento.
- `UC3 - Desenvolver algoritmos/` — fluxogramas, pseudocódigos (.ALG) e exercícios práticos.
- `UC4 - Analisar programação estruturada e orientada a objetos/` — exemplos em JavaScript (abstração, herança, polimorfismo) e pequenos projetos front-end.
- `UC5 - Desenvolvimento desktop/` — projetos e atividades em Python, com exemplos de arquitetura em camadas.
- `UC6 - Criar e manter banco de dados/` — modelagem (DER), scripts e anotações sobre SQL.

## Como navegar

- Abra o README de cada UC para uma visão detalhada do conteúdo daquela unidade (por exemplo, `UC1 - Analisar requisitos and .../README.md`).
- Para diagramas `.drawio`, use draw.io para abrir e editar os arquivos.
- Para projetos Python, consulte o README dentro de cada `python/projetoXX/` para instruções de execução.
